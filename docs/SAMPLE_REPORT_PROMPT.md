# Sample report prompt (fictional data)

Use this to turn a real campaign-tracking or sentiment-analysis report into a **fictional sample** that is safe
for the portfolio. Paste everything between the lines into another AI (ChatGPT, Gemini, Claude), then attach or
paste the report.

**Before you paste a real report:** check that sharing it with an outside AI tool is allowed under vivo's policy.
If you are unsure, first replace creator names, costs and agency names yourself (even with "Creator 1",
"AED ___"), and let the AI do the rest.

When it is done, send the outputs (sections A–D below) and any images back for the portfolio.

---

You are helping me build a **fictional sample report** for my public portfolio. I am a Consumer Insights & Data
Analyst at a smartphone brand in the Middle East. I build two kinds of social media reports:

1. **Campaign tracking**: how a smartphone launch campaign performed across TikTok, Instagram and YouTube, creator
   by creator (KOL / influencer), compared with earlier launches and competitors.
2. **Sentiment analysis**: what audiences said in the comments on those campaign posts, classified as positive,
   neutral or negative, grouped into themes (camera, design, battery, price, and so on), compared across platforms
   and between the UAE and KSA.

The real reports are confidential. I will give you one real report as a **template only**. Your job is to
produce a new report with the **same structure, sections, chart types, level of detail and writing style**, but
with **every confidential detail replaced by invented ones**. A reader should understand exactly what kind of
analysis I do, without learning anything real.

## What you must replace (all of it, every time it appears, including inside charts and tables)

| In the real report | Replace with |
| --- | --- |
| Creator / influencer names, handles, profile links, photos | Invented handles that are clearly fictional, e.g. `@techwithnour_demo`, `@dxb.gadgetlab_demo`. Never a real account. Check the handle does not obviously belong to a real creator. |
| Follower counts, views, likes, comments, shares, saves, reach, impressions, engagement rate | New invented numbers. Do **not** scale the real ones by a fixed factor or round them; make new values that are realistic for the Middle East but not derivable from the originals. Keep them internally consistent (engagement rate = engagements ÷ views, totals add up). |
| Costs, fees, budgets, rates, CPM / CPV / CPE, ROI, sales or revenue | Remove every currency amount. Where a cost metric is part of the analysis, show it as an index (e.g. "Cost efficiency index: 0.8–1.4, 1.0 = campaign average") or as a relative label (Low / Medium / High). |
| Agency, vendor or partner names | "Agency A", "Media partner B", or remove. |
| Internal targets, KPIs set by management, forecasts | Remove, or replace with an obviously generic target ("Target: +10% vs last launch, illustrative"). |
| Real audience comments (quotes) | Write new, invented comments in the same spirit and language mix (English, Arabic, Hinglish if present). Never copy or lightly edit a real comment. |
| Exact campaign dates, unreleased products, prices | Use a generic period ("Launch week 1–4") and only phones that are already public. Do not mention any unreleased model, price or launch plan. |
| Names of colleagues, managers, employees, internal team names, file paths, internal tool or system names | Remove. |
| How the data was collected (tools, APIs, scrapers, data sources, internal dashboards, page set-up) | Remove completely. Describe only **what the analysis shows**, never how it was built or where the data came from. |

Keep the **phone models** generic or use public model names only if I say so. Default: use "Phone X (launch)",
"Phone Y (previous launch)", "Competitor phone".

## What you must keep

- The structure: same sections, same order, same headings (reword headings only if they contain confidential
  details).
- The **type** of every chart and table (bar, line, donut, heat map, ranking table, theme matrix), with new data.
- The kind of insight and recommendation I write ("Creator B drove the most engagement but sentiment on price
  was weaker; next launch, brief creators on value messaging"), rewritten to fit the new fictional numbers.
- Realistic proportions: positive/neutral/negative splits, platform mix and creator spread should look like a real
  Middle East smartphone campaign, without matching the original.

## Label everything

- Put this line at the top of the report and in the footer of every page or slide:
  **"Sample report: all creators, numbers and comments are fictional. Real campaign reports are confidential."**
- Every chart gets a small caption: **"Illustrative data"**.

## What to give me back

**A. The sample report**, complete, in the same format as the original (slide-by-slide outline if it was a deck,
sections if it was a document). For each chart, include the full data table you used.

**B. A portfolio summary** I can paste on my website:
- a title (max 8 words)
- one sentence on what the report answers
- 3–5 bullet "what it shows" points, written for a hiring manager, no numbers that look like real results, no
  tools or data sources

**C. Image prompts**: one prompt per key chart or slide (3–6 in total) so I can generate clean images of the
sample report with an image AI. Each prompt must:
- describe a flat, front-on dark dashboard or slide at 1600×1000 (16:10)
- use background `#0a0d10`, card colour `#141920`, thin light borders, lime accent `#d2f852`, grey `#94a3b8`,
  and muted red only for negative sentiment
- show the fictional numbers and labels from section A exactly, in a clean sans-serif font, large enough to read
- include the caption "Illustrative data" in a corner
- contain **no faces, no photos of people, no real creator avatars** (use initials in circles), and **no real
  brand or platform logos** (use simple generic icons)

**D. Confidentiality check**: a checklist confirming each item in "What you must replace" was handled, with
"Done" or "Not present". **Do not repeat any original name, number, cost or comment in this checklist or
anywhere else in your answer.**

If anything in the original report is unclear, invent a plausible fictional version rather than asking me for
the real detail.
